Install

install.sh copies themes into ~/.config/omarchy/themes. It installs the night and day variants of a theme unless you pick one with --variant. It never replaces a theme that you made.

One drink, night and day, no clone

$ curl -fsSL https://bjarneo.github.io/coffee-themes/install.sh \
    | bash -s -- cappuccino --set

One variant only

$ curl -fsSL https://bjarneo.github.io/coffee-themes/install.sh \
    | bash -s -- cappuccino --variant day --set

All 164 themes

$ git clone --depth 1 https://github.com/bjarneo/coffee-themes ~/.local/share/coffee-themes
$ ~/.local/share/coffee-themes/install.sh --all
$ omarchy theme set cappuccino-night

Apply with Aether

Select a drink and a variant, then select Apply with Aether. Aether downloads colors.toml and a 3840×2160 copy of the background, then applies them at once. Install as Omarchy theme adds the variant to the Omarchy theme menu.

Variants: night and day. Theme names end in -night or -day, for example mocha-night. Other options: --all, --list, --update, --remove, --link and --force. Run install.sh --help for details.

Each palette starts from the drink: its background, its signature color and a second color for the window borders. The 6 main ANSI colors reach at least 5.5:1 against the background at night and 4.5:1 in the day, the WCAG AA level.

The scripts in tools/ draw the backgrounds, the desktop screenshots and the video. Omarchy is at omarchy.org.
